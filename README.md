# Snake-game

Snake Game 🐍

A simple Snake game made with Java Swing.

How to Play:
- Use the arrow keys to move the snake.
- Eat the apple to grow longer.
- Avoid hitting the walls or your own tail.
- The game ends with "Game Over" when you collide.

How to Run:
- Open the project in your IDE (NetBeans, IntelliJ, Eclipse).
- Run the SnakeGame class.
